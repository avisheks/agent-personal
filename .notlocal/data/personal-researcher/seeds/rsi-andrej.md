When people mention “recursive self-improvement” (RSI) in connection with Andrej Karpathy, they’re usually referring to a growing idea in AI:

AI systems helping improve the next generation of AI systems — including potentially improving themselves.

Karpathy has become one of the most visible public voices discussing this transition from:

humans manually tuning models,
to
AI agents autonomously running experiments, editing code, evaluating results, and iterating.
The Core Idea

Recursive self-improvement means:

An AI system modifies or improves some part of itself
The improved system becomes better at making future improvements
This creates a feedback loop

The long-term theoretical version is sometimes called an “intelligence explosion.”

A simplified loop looks like:

AI model →
improves training/code/research →
becomes more capable →
improves itself better →
repeat

Karpathy’s framing is usually more practical and engineering-oriented than sci-fi.

Why Karpathy Matters Here

Karpathy is influential because he has:

deep research credibility from OpenAI
real-world AI systems experience from Tesla
strong educational communication skills
a reputation for identifying important engineering trends early

He popularized ideas like:

“software 2.0”
“vibe coding”
AI coding agents
autonomous research loops

More recently, he discussed what he called the “loopy era” of AI systems — agents continuously improving code and research workflows.

AutoResearch: Karpathy’s Concrete Example

The biggest reason RSI became associated with Karpathy recently is his open-source project called “AutoResearch.”

The idea:

an LLM proposes changes to ML training code
runs experiments
evaluates metrics
keeps improvements
repeats automatically

People describe it as:

“recursive self improvement… something you can actually run.”

According to reports:

the system ran hundreds of experiments autonomously
modified training code
optimized models with minimal human intervention
operated in a constrained experimental loop

This is important because it moves RSI from:

philosophical speculation
to
practical engineering systems.
Important Nuance: This Is NOT Full AGI Self-Improvement

Current systems are still narrow and bounded.

Today’s “recursive self-improvement” usually means:

optimizing training pipelines
hyperparameter search
code generation
experiment automation
agentic software engineering

Not:

rewriting their entire architecture independently
inventing radically new intelligence
escaping human control

Even papers on the topic explicitly say modern systems are only partial forms of RSI. For example, the paper:

Self-Taught Optimizer (STOP) paper

showed language-model-driven systems improving code scaffolds recursively, but noted this is not yet “full recursive self-improvement.”

Why AI Labs Care So Much

This matters because AI progress is increasingly bottlenecked by:

researcher productivity
experimentation speed
infrastructure tuning
data curation
evaluation loops

If AI agents can accelerate those workflows:

frontier model development speeds up
fewer humans are needed per experiment
research throughput compounds

That’s why many people think RSI may emerge gradually rather than as a sudden singularity.

A practical sequence might be:

Copilot coding →
AI agents fixing bugs →
AI agents running experiments →
AI agents optimizing training →
AI agents designing architectures →
partially autonomous AI R&D

Karpathy’s recent comments strongly suggest he believes we are already entering the early stages of this process.

The Research Background

The idea predates modern LLMs by decades.

Key historical roots include:

I.J. Good’s “intelligence explosion” concept (1965)
Seed AI ideas from Eliezer Yudkowsky
Nick Bostrom’s Superintelligence
modern self-improving code generation systems

Some relevant technical work:

Bounded Recursive Self-Improvement
STOP: Self-Taught Optimizer
Why This Is Especially Relevant to Your World (Ads / Foundation Models)

For adtech and foundation models, RSI-like systems are extremely plausible because many workflows are already measurable and automatable:

model evaluation
reward optimization
feature engineering
retrieval tuning
prompt optimization
synthetic data generation
policy tuning
agent-based experimentation

A Walmart Ads foundation model could eventually:

propose new ranking objectives
run offline evaluations
synthesize training data
generate new agent tools
optimize campaign simulators
refine prompts/evaluators
improve its own orchestration stack

That is essentially a bounded form of recursive self-improvement.

The important distinction:

“hard RSI” = fully autonomous intelligence explosion
“soft RSI” = AI accelerating AI engineering workflows

The industry is already moving toward the second one.
