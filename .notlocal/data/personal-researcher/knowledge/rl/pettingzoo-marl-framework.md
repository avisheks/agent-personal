# PettingZoo MARL Framework

**PettingZoo** is a Python library that provides a standardized API for multi-agent reinforcement learning (MARL) environments. Developed by the Farama Foundation, it serves as the multi-agent equivalent of Gymnasium (formerly OpenAI Gym) for single-agent reinforcement learning. ^[multi-agent-rl-ecosystems-success-stories-advertising-applications.md]

## Overview

PettingZoo offers a unified interface for MARL research and development, supporting environments with variable numbers of agents. The framework is designed to facilitate experimentation across different multi-agent scenarios while maintaining consistency in the API structure. As of June 2026, PettingZoo has garnered 3.4K GitHub stars and remains actively maintained. ^[multi-agent-rl-ecosystems-success-stories-advertising-applications.md]

## Key Features

### API Standardization
PettingZoo provides a consistent API standard for MARL environments, enabling researchers to easily switch between different multi-agent scenarios without changing their core algorithm implementations. This standardization has made it a popular choice for academic research and prototyping. ^[multi-agent-rl-ecosystems-success-stories-advertising-applications.md]

### Variable Agent Support
The framework supports environments with variable numbers of agents, making it suitable for scenarios ranging from simple two-agent interactions to more complex multi-agent systems. This flexibility allows researchers to scale their experiments according to their specific requirements. ^[multi-agent-rl-ecosystems-success-stories-advertising-applications.md]

## Position in MARL Ecosystem

PettingZoo operates in the 2-20 agent scale range, positioning it alongside other frameworks like EPyMARL, SMAC, [[JaxMARL]], HARL, and BenchMARL. For larger-scale applications requiring hundreds to millions of agents, researchers typically turn to frameworks like [[MAgent2]] or specialized mean-field approaches. ^[multi-agent-rl-ecosystems-success-stories-advertising-applications.md]

## Comparison with Other Frameworks

In the broader MARL ecosystem, PettingZoo competes with several other notable frameworks:

- **OpenSpiel** (DeepMind): 5.3K stars, focuses on game theory integration with broader game coverage
- **Unity ML-Agents**: 19.5K stars, specializes in 3D game engine integration
- **RLlib**: Part of the Ray ecosystem with 35K+ stars, designed for production-scale distributed training
- **[[JaxMARL]]**: 814 stars, offers up to 12,500x speedup through JAX optimization ^[multi-agent-rl-ecosystems-success-stories-advertising-applications.md]

## Applications and Use Cases

While PettingZoo itself is primarily a research tool, the broader MARL ecosystem it supports has found applications in various domains including energy systems, finance, traffic management, and online advertising. The framework's standardized API makes it particularly valuable for academic research and algorithm development in multi-agent scenarios. ^[multi-agent-rl-ecosystems-success-stories-advertising-applications.md]
