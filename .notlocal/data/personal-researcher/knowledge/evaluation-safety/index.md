# Knowledge Base Index

## General
- [Adversarial Red-Teaming](adversarial-red-teaming.md) — Systematic security evaluation using taxonomy-driven attack categories including prompt injection, jailbreaks, goal hijacking, and privilege escalation with measurable attack success rates.
- [Evaluation as Release Gate](evaluation-as-release-gate.md) — Organizational design pattern where evaluation systems serve as trusted, fast, and unambiguous decision points for production releases with different rigor levels based on risk.
- [Five-Layer Evaluation Stack](five-layer-evaluation-stack.md) — A hierarchical evaluation framework with increasing semantic depth and cost: deterministic tests, domain benchmarks, LLM-as-judge, human expert review, and shadow production testing.
- [Hallucination Detection Pipeline](hallucination-detection-pipeline.md) — Systematic approach to detecting fabricated content through claim extraction, source mapping, NLI-based entailment checking, and FActScore calculation for measuring groundedness.
- [LLM-as-Judge with Calibration](llm-as-judge-with-calibration.md) — Using one LLM to evaluate another's outputs with systematic bias correction through cross-family judging, position randomization, and monthly calibration against human experts.
- [Meta-Evaluation](meta-evaluation.md) — Systematic evaluation of the evaluation system itself, including judge calibration tracking, adversarial testing of evaluators, and correlation analysis between evaluation scores and production outcomes.
- [Segment-Aware Evaluation](segment-aware-evaluation.md) — Evaluation approach that prevents aggregate metrics from hiding critical failures by mandatory slicing across content types, risk levels, locales, and user segments.
- [Trajectory Evaluation](trajectory-evaluation.md) — Agent evaluation methodology that scores multi-step sequences rather than just final outputs, assessing path efficiency, safety, and step-by-step correctness.
