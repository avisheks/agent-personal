# Dual-Level Semantic Matching

**Dual-Level Semantic Matching** is a mechanism used in vision-language model fine-tuning to improve the identification and handling of noisy labels in training datasets. The approach combines macro-level and micro-level textual prompts to create more effective criteria for distinguishing between clean, ambiguous, and noisy samples during the training process.

## Overview

Traditional approaches to handling noisy labels in vision-language models often rely on single-level prompting mechanisms, which can struggle to effectively separate clean samples from noisy ones in the loss space. Dual-level semantic matching addresses this limitation by leveraging two complementary types of textual prompts that provide different perspectives on image-text alignment. ^[0568.md]

The mechanism is particularly valuable when fine-tuning pre-trained vision-language models like CLIP, where the quality of image-text matching directly impacts the model's ability to learn from potentially mislabeled training data. ^[0568.md]

## Components

### Macro-Level Textual Prompts

Macro-level prompts follow the standard CLIP design pattern, using simple class name templates to generate textual descriptions. For a given class j, the macro-level textual prompt is defined as:

`Tmac_j = 'a photo of a {classj}.'`

These prompts ensure inter-class separability but are prone to overfitting noisy samples due to the simplicity of the image-language matching process. The text encoder processes these prompts along with learnable prompts to produce embedding vectors that are used to compute class probabilities. ^[0568.md]

### Micro-Level Textual Prompts

Micro-level prompts incorporate detailed class-specific features such as shapes, textures, colors, and other unique attributes. For class j, the micro-level textual prompt is expressed as:

`T mic_j = 'a photo of a {class j}, which is/has {features of class j}.'`

These prompts provide more reliable matching by describing fine-grained attributes, which reduces overfitting to noisy samples. However, they may cause underfitting on clean samples due to their specificity. ^[0568.md]

## Label Screening Criterion

The dual-level semantic matching mechanism uses a comprehensive loss function that combines three key components to evaluate sample quality:

### Cross-Entropy Loss
The cross-entropy loss evaluates the discrepancy between predicted class probabilities from both macro-level and micro-level prompts and the observed labels. ^[0568.md]

### Consistency Constraint
A consistency constraint is imposed between predictions generated by macro-level and micro-level prompts using Jensen-Shannon divergence. This constraint helps mitigate the impact of noisy labels by promoting agreement between the two prediction levels, effectively reducing overfitting to mislabeled data. ^[0568.md]

### Entropy Penalty
An entropy penalty term encourages more confident predictions by penalizing overly smooth outputs, designed to reduce overlap between clean and noisy samples in the loss space. ^[0568.md]

## Sample Classification

The dual-level semantic matching mechanism enables tri-segment sample screening, which categorizes training samples into three distinct groups:

- **Clean samples**: Those with low loss values that likely have correct labels
- **Ambiguous samples**: Those with intermediate loss values that may have uncertain label quality  
- **Noisy samples**: Those with high loss values that likely have incorrect labels

This classification is achieved by modeling sample-wise losses with a two-component Gaussian Mixture Model and defining ambiguous regions based on the overlap between clean and noisy data distributions. ^[0568.md]

## Effectiveness

Experimental results demonstrate that dual-level semantic matching significantly reduces the overlap between clean and noisy samples compared to using either macro-level or micro-level prompts alone. This improved separation enables more accurate identification of mislabeled samples and better handling of label noise during training. ^[0568.md]

The approach has shown superior performance across multiple datasets when dealing with various types of label noise, including both symmetric flip noise and more challenging pairwise flip noise scenarios. ^[0568.md]
