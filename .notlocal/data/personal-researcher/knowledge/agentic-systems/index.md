# Knowledge Base Index

## General
- [Agent State Space Explosion](agent-state-space-explosion.md) — The computational challenge where multi-step agents face exponentially growing possible action sequences, requiring bounded search strategies.
- [Agentic Cost Optimization](agentic-cost-optimization.md) — Systematic approaches to reduce the computational cost of multi-step agent tasks through plan templates, model routing, and step consolidation.
- [Human-in-the-Loop Agent Design](human-in-the-loop-agent-design.md) — Architectural patterns for integrating human oversight and approval into agent workflows, balancing autonomy with safety and trust.
- [Multi-Agent Orchestration](multi-agent-orchestration.md) — An architectural pattern where specialist agents handle different domains with a central orchestrator managing task routing, state, and inter-agent communication.
- [Prompt Injection via Tool Responses](prompt-injection-via-tool-responses.md) — A security vulnerability where malicious instructions embedded in tool outputs can hijack agent behavior and trigger unauthorized actions.
- [ReAct Pattern](react-pattern.md) — An agentic reasoning pattern that interleaves Thought → Action → Observation cycles to make agent decision-making transparent and debuggable.
- [Tool Selection as Contextual Bandit](tool-selection-as-contextual-bandit.md) — A formalization of agent tool selection as a contextual bandit problem where the agent learns optimal tool choices based on task context and historical outcomes.
- [Trajectory-Level Evaluation](trajectory-level-evaluation.md) — An evaluation methodology for agents that assesses the entire sequence of actions and decisions, not just the final output quality.
