# Claude Mythos 5

**Claude Mythos 5** is Anthropic's most advanced AI model, released on June 9, 2026, as part of the restricted Project Glasswing program. It represents the flagship model in [[Anthropic Model Family — Mythos, Fable, Opus, Sonnet, Haiku|Anthropic's model hierarchy]], positioned above [[Claude Fable 5]], [[Claude Opus 4.7]], [[Claude Sonnet 4.6]], and [[Claude Haiku 4.5]]. ^[anthropic-model-family-comparison.md]

## Access and Availability

Claude Mythos 5 is currently available only through invitation-only access via Project Glasswing, with approximately 150 organizations across 15+ countries participating in the restricted program. The model is specifically designed for autonomous cybersecurity vulnerability discovery and biology research applications. ^[anthropic-model-family-comparison.md]

## Technical Specifications

### Context and Output Limits
- **Input context**: 1 million tokens
- **Output context**: 128,000 tokens
- **Knowledge cutoff**: January 2026 ^[anthropic-model-family-comparison.md]

### Pricing Structure
- **Standard pricing**: $10 per million input tokens, $50 per million output tokens
- **Batch pricing**: $5 per million input tokens, $25 per million output tokens
- **Preview/research pricing**: $25 per million input tokens, $125 per million output tokens ^[anthropic-model-family-comparison.md]

## Performance Benchmarks

Claude Mythos 5 demonstrates exceptional performance across multiple evaluation metrics:

- **[[SWE-bench Verified]]**: 93.9% accuracy
- **GPQA Diamond**: 94.6% accuracy  
- **Humanity's Last Exam (with tools)**: 64.7% accuracy
- **CyberGym**: 83.1% accuracy
- **Terminal-Bench 2.0**: 82.0% accuracy ^[anthropic-model-family-comparison.md]

## Key Capabilities

### Autonomous Vulnerability Discovery
Claude Mythos 5 has demonstrated the ability to discover over 10,000 high and critical severity vulnerabilities, including a notable 27-year-old bug in OpenBSD. The model can find vulnerabilities in every major operating system and browser without human steering or guidance. ^[anthropic-model-family-comparison.md]

### Research Applications
The model is specifically optimized for biology research and cybersecurity applications, representing Anthropic's most capable system for autonomous research tasks. ^[anthropic-model-family-comparison.md]

## Relationship to Other Models

Claude Mythos 5 shares the same base model architecture as [[Claude Fable 5]], but Fable 5 includes safety routing that redirects cybersecurity and biology queries to [[Claude Opus 4.8]] instead. This makes Mythos 5 the unrestricted version specifically designed for advanced research applications. ^[anthropic-model-family-comparison.md]

## Model Hierarchy Position

Within Anthropic's model family, Claude Mythos 5 sits at the top of the capability hierarchy:
1. **Claude Mythos 5** (restricted, most capable)
2. [[Claude Fable 5]] (general availability, premium)
3. [[Claude Opus 4.8]] (high capability)
4. [[Claude Sonnet 4.6]] (balanced performance)
5. [[Claude Haiku 4.5]] (fast, efficient) ^[anthropic-model-family-comparison.md]
