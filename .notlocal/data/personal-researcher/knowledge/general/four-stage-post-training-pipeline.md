# Four-Stage Post-Training Pipeline

The **Four-Stage Post-Training Pipeline** is a systematic training methodology used to develop hybrid reasoning models that can seamlessly switch between step-by-step reasoning and low-latency response modes. This approach was implemented in the development of [[Qwen3 Language Model]] to enable its unified thinking and non-thinking capabilities within a single architecture. ^[qwen-3-models-architecture-benchmarks-training-more.md]

## Overview

The four-stage pipeline strategically builds capabilities through sequential phases, with each stage building upon the previous to unify reasoning depth, response speed, and instruction-following in a single model. The methodology addresses the challenge of creating models that can adapt their response strategy dynamically based on query complexity. ^[qwen-3-models-architecture-benchmarks-training-more.md]

## Stage Breakdown

### Stage 1: Long Chain-of-Thought Cold Start

The first stage establishes foundational reasoning capabilities through fine-tuning on diverse long-form [[Chain-of-Thought Reasoning]] datasets. This phase focuses on building competency across multiple domains including:

- Mathematical problem solving
- Code generation and comprehension  
- Logical reasoning
- STEM-domain challenges

This stage creates a strong baseline for multi-step reasoning and symbolic manipulation, which becomes core to the model's thinking mode functionality. ^[qwen-3-models-architecture-benchmarks-training-more.md]

### Stage 2: Reinforcement Learning on Reasoning Tasks

The second stage shifts focus to reinforcement learning specifically targeting reasoning enhancement. Key components include:

- Scaling compute resources for deeper exploration
- Applying rule-based reward functions to optimize CoT depth, logical flow, and answer correctness
- Encouraging development of reasoning paths with both exploration and convergence capabilities

This reinforcement learning phase makes the model more confident and robust in solving problems where trial-and-error reasoning provides benefits. ^[qwen-3-models-architecture-benchmarks-training-more.md]

### Stage 3: Thinking Mode Fusion

The third stage focuses on fusing rapid inference capabilities with deep reasoning through hybrid training approaches:

- Fine-tuning on hybrid datasets combining long CoT samples with traditional instruction-following tasks
- Using instruction-tuning data generated by the improved model from Stage 2 to maintain quality and internal consistency
- Creating unified models that can adapt response strategies dynamically based on query complexity

This hybridization enables downstream applications like AI agents that require both reasoning modes in real-time scenarios. ^[qwen-3-models-architecture-benchmarks-training-more.md]

### Stage 4: General-Purpose Reinforcement Learning

The final stage exposes the model to over 20 general-domain tasks via reinforcement learning to enhance broad capabilities:

- Instruction and format following
- Agentic tool use and execution planning
- Reducing hallucinations and undesirable behaviors
- Enhancing response helpfulness and coherence in multi-turn dialogue

This phase tunes the model for broad generalization, making it viable for real-world deployment across diverse domains. ^[qwen-3-models-architecture-benchmarks-training-more.md]

## Applications

The four-stage pipeline enables the development of models with [[Unified Thinking and Non-Thinking Modes]], allowing dynamic switching between:

- **Thinking Mode**: Designed for tasks requiring multi-step reasoning such as coding, mathematics, or logical inference
- **Non-Thinking Mode**: Optimized for general-purpose tasks like casual dialogue, retrieval, or lightweight summarization

This architecture enables [[Thinking Budget Mechanism]] control, providing a practical method for balancing latency, cost, and output quality based on task complexity. ^[qwen-3-models-architecture-benchmarks-training-more.md]

## Technical Implementation

The pipeline leverages several advanced training techniques:

- Integration with [[Mixture of Experts (MoE)]] architectures for efficient parameter utilization
- Compatibility with [[Long-Context Scaling]] for processing extended inputs
- Support for [[Supervised Fine-Tuning (SFT)]] methodologies in the instruction-following phases

The methodology has been successfully implemented in models ranging from lightweight variants to large-scale systems with hundreds of billions of parameters. ^[qwen-3-models-architecture-benchmarks-training-more.md]

## Benefits

The four-stage approach provides several key advantages:

- **Unified Architecture**: Eliminates the need for separate reasoning and instruction-following models
- **Dynamic Adaptation**: Enables real-time switching between response strategies based on task requirements
- **Scalable Training**: Provides a systematic framework that can be applied across different model sizes
- **Quality Maintenance**: Uses self-generated data to maintain consistency and reduce distribution shift

This methodology represents a significant advancement in post-training techniques for large language models, enabling the creation of more versatile and efficient AI systems. ^[qwen-3-models-architecture-benchmarks-training-more.md]
