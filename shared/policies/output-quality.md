# Output Quality Policy (v1)

Cross-skill standards for output quality. Skills may reference this policy
to inherit shared quality expectations.

## Completeness

- All sections specified in the skill SOP must be present in output.
- No placeholder text (e.g., "TBD", "TODO", "...") in final output.
- All hyperlinks must be valid and point to the claimed content.

## Accuracy

- Factual claims must be verifiable against input data or cited sources.
- Numerical computations must be reproducible from the input.
- Dates and day-of-week labels must be calendar-correct.

## Formatting

- Output format must match the SOP specification exactly.
- Tables must have consistent column counts across all rows.
- Markdown must render correctly (no broken links, unclosed formatting).

## Timeliness

- Output must reflect the most current input data available.
- References to external sources should be from the specified date range.
